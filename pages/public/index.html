Basic text editor to encrypt fast and easy text

ct

Type a secret, protect it with AES-128-GCM, then save it as a .ct file — or hide the encrypted text inside a PNG image. Use the desktop GUI or the headless ct_nox command line tool.

What it does

Strong encryption

AES-128-GCM, an AEAD mode for symmetric-key cryptography. Keys are derived from your password with PBKDF2-HMAC-SHA256 and a random salt.

Text & password

Type or paste text into the editor, add a password, and encrypt or decrypt it immediately. No accounts, no cloud, no setup.

Open & save CT files

Open CT File decrypts an existing encrypted file; Save CT File encrypts your text and writes it to disk.

Save as image

Export Image encrypts the text and encodes it as a 256×256 PNG with a binary frame around the ct logo. The frame grows automatically for longer messages.

Import from image

Import Image reads the binary frame from a PNG and decrypts the hidden text with your password. Works with files produced by the GUI or the CLI.

GUI and CLI

The GUI is the everyday editor. ct_nox is the windowless companion for scripts, pipelines and other programs.

Standard ct format

Encrypted text is stored as v2/pbkdf2-sha256/{iterations}/{salt}/{nonce}/{ciphertext}/{mac} — hex encoded, portable and verifiable.

Portable builds

Built with Rust and eframe/egui. Release builds are published for Linux, Debian, Windows and macOS.

GUI workflow

  1. Run ct and type or paste your text.
  2. Enter a password.
  3. Open CT File — decrypt an encrypted file.
  4. Save CT File — encrypt and save to a .ct file.
  5. Export Image — encrypt the text and save it as a PNG image.
  6. Import Image — select a PNG, enter the password, and read the decrypted text.

The same export/import actions are also available from the File menu as Export as Image and Import from Image.

Command line — ct_nox

Everything the GUI can do is available headless. Use it from scripts or to move encrypted data between programs.

# encrypt / decrypt text
ct_nox encrypt -t "hello world" -p "mypassword"
ct_nox decrypt -t "encrypted_output" -p "mypassword"

# encrypt / decrypt files
ct_nox encrypt -f document.txt -p "mypassword" -o document.ct
ct_nox decrypt -f document.ct -p "mypassword"

Save secrets as an image

Image Strip encoding hides the encrypted text in the outer pixels of a PNG. Each character becomes 8 pixels (black = 1, white = 0) placed clockwise around the frame, with the ct logo in the center. A 256×256 image holds 127 characters; larger contents grow the image in 16-pixel steps. 

# save encrypted text as a PNG image
ct_nox image-encode -t "my secret message" -p "password123" -o output.png
ct_nox image-encode -f secret.txt -p "password123" -o output.png

# read it back
ct_nox image-decode -f output.png -p "password123"

Full format and pixel layout: IMAGE_STRIP.md.

Quick start

cargo build --release
./target/release/ct      # GUI
./target/release/ct_nox  # CLI

On Linux, install the GUI build dependencies first:

sudo apt-get install -y libclang-dev libgtk-3-dev \
  libxcb-render0-dev libxcb-shape0-dev libxcb-xfixes0-dev \
  libxkbcommon-dev libssl-dev
